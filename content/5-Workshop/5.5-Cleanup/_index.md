#### Objectives

* Learn how to apply VPC Endpoint Policies to restrict service access permissions.
* Write VPC Endpoint policies granting only necessary S3 actions.
* Test policies by accessing services from VPC with different accounts.

#### Practical Exercises

1. Read about VPC Endpoint Policy and application scope.
2. Write policies to restrict access solely to specified S3 buckets.
3. Attach policy to VPC Endpoint.
4. Test S3 access with policy and compare behaviors when policy is denied.
