&emsp;During the FCAJ internship, I participated in a total of 3 events, each providing a different and valuable learning experience. Through these events, I expanded my knowledge of AWS Cloud Architecture, cloud monitoring, security, certification, Agentic AI, and modern software development. I also had opportunities to improve my problem-solving, teamwork, communication, and technical decision-making skills through competitive activities, technical sharing sessions, and discussions with experienced professionals and other students. These experiences helped me better understand how cloud and AI technologies are applied in real-world projects and provided valuable insights into the skills expected from future cloud and software engineers.

### [Event 1](4.1-Event1/)

&emsp;**Event Name:** AWS Cloud Architecture Challenge

&emsp;**Time:** June 20, 2025

&emsp;**Role in Event:** Participant

&emsp;**Main Content and Key Activities:**
- Participated in a competitive AWS Cloud Architecture quiz with eight teams, each consisting of five university students.
- Answered 10 questions covering AWS services, networking, compute, storage, databases, security, scalability, availability, and cost optimization.
- Worked with team members to analyze architectural scenarios, compare possible AWS solutions, and make decisions within a limited amount of time.
- Experienced an increasing difficulty and point-value system, which encouraged strategic decision-making and careful evaluation of more complex questions.
- Applied AWS knowledge to practical architecture scenarios rather than relying only on memorization of individual AWS services.

&emsp;**Results and Values Achieved:**
- Strengthened my understanding of AWS services and their practical use cases.
- Learned that effective cloud architecture requires considering multiple factors, including security, scalability, reliability, performance, and cost.
- Improved technical problem-solving and decision-making skills by comparing different architectural approaches and their trade-offs.
- Developed teamwork, communication, and time-management skills while solving technical problems under competitive time constraints.
- Realized that strong AWS fundamentals are essential for analyzing and designing more complex cloud architectures.

### [Event 2](4.2-Event2/)

&emsp;**Event Name:** AWS Community Sharing – Monitoring, Security, and AWS Cloud Practitioner

&emsp;**Time:** July 11, 2025

&emsp;**Role in Event:** Attendee

&emsp;**Main Content and Key Activities:**
- Learned about Service Level Agreements (SLAs) and the importance of monitoring systems based on actual user and business experience rather than infrastructure metrics alone.
- Explored monitoring strategies using services such as Amazon CloudWatch and Amazon SNS to detect issues and proactively notify teams.
- Learned about Agentic AI for web application security, including architecture review, code security review, and automated penetration testing.
- Explored the AWS Certified Cloud Practitioner (CLF-C02) certification structure, including Cloud Concepts, Security and Compliance, Cloud Technology and Services, and Billing, Pricing and Support.
- Learned practical study methods such as understanding services through use cases, reviewing practice-test mistakes, and gaining hands-on experience with AWS Free Tier.

&emsp;**Results and Values Achieved:**
- Developed a better understanding of how monitoring should focus on customer experience and business outcomes rather than infrastructure health alone.
- Learned how AI-powered security tools can automate parts of the security lifecycle while still requiring human validation and expertise.
- Strengthened my understanding of important AWS fundamentals such as IAM, the Shared Responsibility Model, AWS global infrastructure, pricing models, and common AWS services.
- Gained a clearer roadmap for preparing for the AWS Cloud Practitioner certification.
- Learned how cloud operations, security, and certification knowledge can be combined to build a stronger foundation for a career in cloud computing.

### [Event 3](4.3-Event3/)

&emsp;**Event Name:** FCAJ x Agentic AI Build Week: Show Up. Build. Pitch. WIN!

&emsp;**Time:** July 25, 2026

&emsp;**Role in Event:** Participant

&emsp;**Main Content and Key Activities:**
- Learned about Agentic AI and how autonomous AI agents differ from traditional AI assistants.
- Explored how AI agents can perform planning, reasoning, tool usage, and decision-making to complete complex tasks.
- Learned how AI can support software development through code generation, debugging, testing, documentation, and rapid prototyping.
- Explored the process of building AI-powered applications by combining Large Language Models (LLMs), external APIs, cloud services, and agent frameworks.
- Learned modern project development practices, including AI-assisted brainstorming, iterative development, teamwork, project organization, and technical presentation.
- Observed project demonstrations and learned how teams communicate their technical solutions, innovation, implementation, and business value through project pitching.

&emsp;**Results and Values Achieved:**
- Gained a stronger understanding of Agentic AI and its potential applications in modern software development.
- Learned how AI can improve developer productivity while still requiring human oversight to ensure the quality and correctness of generated solutions.
- Improved my understanding of how AI can be integrated with cloud services and external APIs to create intelligent and scalable applications.
- Learned the importance of defining a clear problem before implementation and using iterative development to improve project quality.
- Improved my awareness of the importance of teamwork, technical communication, and presentation skills when delivering a software project.

### Overall Results and Values

&emsp;Across these three events, I gained a broader perspective on the skills and knowledge required to work effectively in cloud computing and modern software development. The **AWS Cloud Architecture Challenge** strengthened my ability to analyze cloud architecture problems and make technical decisions based on system requirements and trade-offs. The **AWS Community Sharing** event expanded my understanding of real-world cloud operations, monitoring, security, and professional certification. Finally, the **Agentic AI Build Week** introduced me to emerging AI technologies and demonstrated how AI can be integrated into software development and cloud-based applications.

&emsp;Beyond technical knowledge, these events also helped me develop important soft skills such as teamwork, communication, time management, critical thinking, and technical presentation. More importantly, I learned that successful technology projects require more than knowledge of individual tools or services. Engineers need to understand the requirements of a system, evaluate different solutions, consider trade-offs, communicate effectively, and continuously learn new technologies.

&emsp;Overall, these experiences provided valuable exposure to both the technical and professional aspects of the technology industry. They helped me better understand how AWS Cloud, security, monitoring, and Agentic AI are being applied in real-world environments and gave me a clearer direction for developing the technical and soft skills needed for future cloud and software engineering projects.
