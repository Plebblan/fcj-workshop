# Summary Report: “AWS Community Sharing – Monitoring, Security, and AWS Cloud Practitioner”

### Event Objectives

- Introduce best practices for monitoring cloud applications and understanding Service Level Agreements (SLAs).
- Demonstrate how Agentic AI can enhance web application security through automated security analysis and penetration testing.
- Provide an overview of the AWS Certified Cloud Practitioner (CLF-C02) certification and effective preparation strategies.
- Help participants strengthen their knowledge of AWS services, cloud operations, security, and certification pathways.

### Speakers

- **Nguyen Huynh Son** – *SLA and Monitoring: From SLA to Monitoring What Really Matters*
- **Nguyen Tuan Thinh** – *Securing Your Web Apps With AWS Security Agent*
- **Ngo Le Tan Huy** – *Inside the Exam: AWS Cloud Practitioner*

### Key Highlights

#### SLA and Monitoring

- **Understanding SLA**: Explained the role of Service Level Agreements in defining service expectations between providers and customers.
- **User-centric monitoring**: Monitoring should focus on customer experience rather than infrastructure metrics alone.
- **Monitoring Pyramid**: Demonstrated monitoring across multiple layers, including cloud provider, infrastructure, application, business metrics, and customer experience.
- **Alerting workflow**: Showed how CloudWatch Alarms and Amazon SNS can proactively notify teams before service issues become customer complaints.

#### Securing Web Applications with AWS Security Agent

- **Agentic AI for security**: Introduced an autonomous security agent powered by Amazon Bedrock.
- **Complete security lifecycle**: Covered Design Review, Code Security Review, and Automated Penetration Testing.
- **Verifiable vulnerability detection**: The agent validates findings by attempting real exploitation instead of only analyzing code.
- **Current limitations**: Business logic vulnerabilities, MFA, and complex authentication mechanisms still require human expertise.

#### AWS Cloud Practitioner Certification

- **Exam overview**: Explained the structure, domains, and scoring of the AWS Certified Cloud Practitioner (CLF-C02) examination.
- **Four knowledge domains**:
  - Cloud Concepts
  - Security and Compliance
  - Cloud Technology and Services
  - Billing, Pricing, and Support
- **Core concepts**: Reviewed the Shared Responsibility Model, IAM, AWS global infrastructure, pricing models, and common AWS services.
- **Exam preparation tips**: Recommended learning services through use cases, reviewing practice exam mistakes, and gaining hands-on experience with AWS Free Tier.

### Key Takeaways

#### Monitoring Strategy

- **Healthy infrastructure does not always mean happy users**: Infrastructure metrics alone cannot accurately represent customer experience.
- **Business-focused monitoring**: Track metrics such as login success rate, order completion, and user journeys alongside technical metrics.
- **Risk management**: Monitoring plays an essential role in identifying, responding to, and continuously improving service reliability.

#### Security Automation

- **Shift-left security**: Integrate security reviews earlier in the software development lifecycle.
- **AI-assisted security testing**: Agentic AI can automate architecture reviews, code scanning, and penetration testing.
- **Human oversight remains essential**: Security professionals are still required to validate findings and assess business-specific risks.

#### AWS Certification Preparation

- **Understand service purposes**: Focus on knowing when and why to use each AWS service instead of memorizing configurations.
- **Hands-on learning**: Practical experience with AWS significantly improves understanding and exam readiness.
- **Effective exam strategy**: Apply elimination techniques, identify keywords, and carefully review incorrect answers during practice tests.

### Applying to Work

- **Implement user-focused monitoring** by measuring customer journeys in addition to infrastructure health.
- **Leverage CloudWatch and Amazon SNS** to build proactive monitoring and alerting systems.
- **Integrate AI-powered security reviews** into software development and DevSecOps workflows.
- **Strengthen AWS fundamentals** through hands-on practice with core AWS services.
- **Apply risk management principles** when designing and operating cloud-based applications.
